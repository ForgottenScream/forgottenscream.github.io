## Overview

This project comes from the Mouseless Dev book by Matthieu Cneude. It started as
a way to store the configuration files for the various tools I used in my setup.

## Motivation

I wanted to be able to restore my setup without having to reconfigure my tools
after a fresh install.

## Challenges

- (At the time) learning Git and Github to store the dotfiles

## What I Learned

- Using symbolic links which helped smooth the setup process.
